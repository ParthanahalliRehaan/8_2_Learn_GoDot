*D3*:*Filter(Not in import panel,Go to Project settings --> Render --> texture filtering --> nearest), Mipmaps, Compress. What are these?*
**Filter**
 - This means the engine will use nearest-neighbor filtering. Pixels are displayed as sharp blocks without smoothing. Great for pixel art, since it preserves crisp edges.
 - Linear (the alternative): Smooths textures when scaled, but can make pixel art look blurry.
**Compressions**
 - Texture compression reduces the amount of memory textures use.
 - Useful for large projects or mobile games where memory is limited.
**MinMaps**
 - Downside: They can make pixel art look softer, so many pixel-art projects disable them.
 - Mipmaps are pre-computed, smaller versions of your texture.
