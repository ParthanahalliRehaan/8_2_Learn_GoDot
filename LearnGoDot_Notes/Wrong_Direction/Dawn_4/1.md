# 9. Create the lore function

Under that, add:

```gdscript
func discover_lore(lore_id: String, continent: String) -> void:
```

At this point the function exists, but does nothing.

Add:

```gdscript
func discover_lore(lore_id: String, continent: String) -> void:
    if not discovered_lore.has(lore_id):
        discovered_lore[lore_id] = {
            "continent": continent,
            "timestamp": Time.get_datetime_string_from_system()
        }
```

Now we're doing three things.

### Check

```gdscript
discovered_lore.has(lore_id)
```

Does this lore already exist?

### Prevent duplicate

```gdscript
if not discovered_lore.has(lore_id):
```

Only continue if it doesn't exist.

### Store

```gdscript
discovered_lore[lore_id] = {...}
```

Add the lore.

The actual roadmap implementation uses this same structure.

# 10. Add feedback

Inside the `if`, underneath the Dictionary:

```gdscript
print("Discovered: %s in %s" % [lore_id, continent])
```

Now the function is:

```gdscript
func discover_lore(lore_id: String, continent: String) -> void:
    if not discovered_lore.has(lore_id):
        discovered_lore[lore_id] = {
            "continent": continent,
            "timestamp": Time.get_datetime_string_from_system()
        }

        print("Discovered: %s in %s" % [lore_id, continent])
```

# 12. Test it

At the bottom:

```gdscript
func _ready() -> void:
    discover_lore("echo_stone", "ashlands")
    discover_lore("dragon_bone", "verdant")

    print("Total lore: %d" % get_lore_count())
```

Complete script:

```gdscript
extends Node


var discovered_lore: Dictionary = {}


func discover_lore(lore_id: String, continent: String) -> void:
    if not discovered_lore.has(lore_id):
        discovered_lore[lore_id] = {
            "continent": continent,
            "timestamp": Time.get_datetime_string_from_system()
        }

        print("Discovered: %s in %s" % [lore_id, continent])


func get_lore_count() -> int:
    return discovered_lore.size()


func _ready() -> void:
    discover_lore("echo_stone", "ashlands")
    discover_lore("dragon_bone", "verdant")

    print("Total lore: %d" % get_lore_count())
```

# 14. Now deliberately break it

This part matters.

Change:

```gdscript
discover_lore("dragon_bone", "verdant")
```

to:

```gdscript
discover_lore("echo_stone", "verdant")
```

Run again.

You should still get:

```text
Discovered: echo_stone in ashlands
Total lore: 1
```

Why isn't it added twice?

Because:

```gdscript
if not discovered_lore.has(lore_id):
```

rejects the second discovery.

That is the sort of debugging and reasoning I want you doing, rather than blindly copying code until Godot stops yelling.

# 15. Dawn 4 Mental Model

```text

    ↓

    ↓

    ↓

    ↓

    ↓
How much state exists?


FOR LOOP
    ↓
Repeat work over a collection


MATCH
    ↓
Choose behavior based on a value
```

And eventually:

```text

        ↓

        ↓
Dictionary
        ↓
GameState
        ↓

```

That last part is why we're learning this now. **You're building the foundation for the actual game's lore system, not doing random GDScript exercises.**
