## 🌅 DAWN 5 — Step-by-Step Walkthrough

### Step 1: Create the `EntityStats` Resource Script

In your Godot project (`continua`), right-click in the **FileSystem dock** and create a new folder:
```
src/resources/
```

Now right-click `src/resources/` → **Create Script**:
- Name: `EntityStats`
- Template: Empty
- Language: GDScript

Paste this exact code:

```gdscript
class_name EntityStats
extends Resource

signal health_changed(new_health: int, max_health: int)
signal entity_died()

@export var max_health: int = 100
var current_health: int:
	set(value):
		current_health = clampi(value, 0, max_health)
		health_changed.emit(current_health, max_health)
		if current_health <= 0:
			entity_died.emit()

func _init() -> void:
	current_health = max_health

func take_damage(amount: int) -> void:
	current_health -= amount

func heal(amount: int) -> void:
	current_health += amount
```

**Save** (Ctrl+S). You now have a globally-typed `EntityStats` resource.

- Save As: `test_entity_stats.tscn`

### Step 3: Attach a Test Script to the Scene

Click the root `Node2D` in the Scene dock. In the Inspector, click the script icon (scroll paper) next to "Script" → **Create Script**:
- Path: `src/test/TestEntityStats.gd`
- Template: Default

Replace the code with:

```gdscript
extends Node2D

func _ready() -> void:
	# Create a new EntityStats resource
	var stats := EntityStats.new()
	
	# Connect to its signals
	stats.health_changed.connect(_on_health_changed)
	stats.entity_died.connect(_on_entity_died)
	
	# Test it
	print("=== EntityStats Test ===")
	print("Initial health: %d/%d" % [stats.current_health, stats.max_health])
	
	stats.take_damage(30)
	stats.take_damage(50)
	stats.take_damage(30)  # Should trigger death (overkill)
	
	stats.heal(20)  # Should do nothing because dead (health clamped at 0)

func _on_health_changed(new_health: int, max_health: int) -> void:
	print("Health changed: %d/%d" % [new_health, max_health])

func _on_entity_died() -> void:
	print("💀 ENTITY DIED!")
```

**Save the script** (Ctrl+S), then **save the scene** (Ctrl+S).

---

## 🧠 What You Just Built

| Concept | Where It Lives | What It Does |
|---|---|---|
| `class_name` | `EntityStats.gd` | Makes `EntityStats` a global type — usable anywhere without `preload()` |
| `extends Resource` | `EntityStats.gd` | Makes it a data container that can be saved/loaded, instanced, and exported in Inspector |
| `signal` | `EntityStats.gd` | Declares events that other nodes can listen to |
| Custom `set` | `current_health` | Runs code every time health changes — clamps value + emits signals |
| `emit()` | In the setter | Fires the signal, notifying all connected listeners |
| `connect()` | `TestEntityStats.gd` | Binds signal to a callback function |
| `_init()` | `EntityStats.gd` | Constructor — runs when `EntityStats.new()` is called |
