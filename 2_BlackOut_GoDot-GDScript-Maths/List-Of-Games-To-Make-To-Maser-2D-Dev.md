## The 5 games (calendar days are a target, not a law — 1-2hr days will slip, that's fine, just don't skip steps)

| # | Game | Days | New concepts forced | Mentoring mode |
|---|------|------|---------------------|-----------------|
| 1 | Dodge-the-Creeps-style arcade | 1–12 | Project setup, GDScript basics, game loop, input, collision/signals, spawning, UI, basic audio | **Guided** — I link docs, you figure out implementation |
| 2 | Simple platformer | 13–24 | CharacterBody2D, physics, TileSet/TileMap, animation state machine, camera follow | **Self-setup** — you write plan.md's Day 0, referencing Game 1's devlog |
| 3 | Top-down mini-adventure | 25–37 | Deeper state machines, inventory system, scene/level transitions, save/load (JSON) | Self-setup |
| 4 | Juicy puzzle/arcade game | 38–49 | Full animation sets, real music track, particles, screen transitions, settings menu | Self-setup, heavier art+audio focus |
| 5 | Capstone (your own concept) | 50–60 | Combine everything, ship to itch.io, postmortem | Fully self-directed |

Only Game 1 gets a full plan.md from me up front (separate file). From Game 2 onward you write the plan.md yourself — I'll review/critique it, not author it. See `game-template-plan.md` for the format and rules that carries forward.
